📸 Jak działa dodawanie wydatku?

1

User robi zdjęcie lub wpisuje tekst

Strona /upload — dwie zakładki: foto albo notatka tekstowa

2

Frontend wysyła do API

POST /api/process-image (multipart) lub POST /api/process-text (JSON) z tokenem Firebase

3

Claude API analizuje

Backend wysyła do Claude — AI wyciąga sklep, datę, sumę i listę pozycji z kategoriami. Dane wracają jako JSON.

4

User widzi podgląd i może edytować

Formularz z wyciągniętymi danymi — można poprawić przed zapisem

5

Zapis do bazy

POST /api/wydatki — zapisuje nagłówek do wydatki i pozycje do pozycje powiązane z household_id
